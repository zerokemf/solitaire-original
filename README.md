# 🃏 經典接龍 | Klondike Solitaire

一個完整的經典接龍（Klondike Solitaire）網頁遊戲，採用原生 JavaScript 開發，無需任何框架或依賴。

## ✨ 功能特色

### 核心遊戲
- 🃏 **完整 Klondike 規則** — 標準 7 列金字塔發牌，支援點擊移動和拖曳操作
- 🔢 **有解遊戲編號** — #1 到 #32000，每一局都保證有解
- 🚫 **死局偵測** — 自動偵測無法繼續遊戲的狀態
- ↶ **無限復原** — 支援完整操作歷史記錄
- 📊 **統計系統** — 記錄勝率、勝場、平均步數、平均時間

### 操作與體驗
- 🖱️ **拖曳移動** — 支援卡片拖放，直覺操作
- 💡 **提示系統** — 一鍵顯示所有可移動的牌
- 🔍 **縮放功能** — 可自由放大或縮小牌面
- 🌙 **明暗主題** — 一鍵切換，深色模式護眼
- 🔊 **音效系統** — 點擊聲、勝利音效（可開關）

### 挑戰模式
- ⏱️ **計時挑戰** — 在限時內完成考驗
- 📋 **難度切換** — 簡單/普通/困難，發牌方式不同

### 其他
- 💾 **自動存檔** — 關閉頁面再回來可以繼續上局
- ⌨️ **鍵盤支援** — 快捷鍵操作（可擴充）

## 🚀 如何遊玩

### 直接開啟
1. 下載或 clone 此專案
2. 用瀏覽器開啟 `index.html` 即可開始

### 本地開發 Server
```bash
# Python 3
python -m http.server 8000

# Node.js (npx)
npx serve .

# 或使用 VS Code Live Server 擴充
```

開啟後在瀏覽器輸入 `http://localhost:8000` 即可。

## 🎮 操作說明

### 基本規則
- 將紙牌按 **紅黑交替遞減** 的順序排列（K→Q→J→10→...→A）
- 將所有紙牌移動到右上角四個花色疊牌區即獲勝
- 每個花色疊牌區必須從 **A** 開始，按 **遞增** 排列（A→2→3→...→K）

### 操作方式
| 操作 | 說明 |
|------|------|
| 點擊兩次 | 自動移動到目標位置 |
| 拖曳 | 將卡片拖到目標位置 |
| 點擊發牌疊 | 從發牌堆翻牌 |
| 點擊重玩 | 開新遊戲 |

### 快捷功能
| 按鈕 | 功能 |
|------|------|
| 新遊戲 | 重新開始一局 |
| ↶ 復原 | 回上一手 |
| 💡 提示 | 顯示可移動的牌 |
| 🌙 主題 | 切換明/暗模式 |
| 📋 難度 | 切換發牌難度 |
| 📊 統計 | 查看歷史戰績 |

## 🛠️ 技術規格

- **語言：** 原生 JavaScript（無框架）
- **標記：** HTML5 + CSS3（CSS 變數支援明暗主題）
- **特色：** 使用 CSS `vmin`/`vmax` 實現響應式設計，適配各種螢幕尺寸
- **儲存：** LocalStorage 自動存檔
- **數量：** 52 張標準撲克牌（不含鬼牌）
