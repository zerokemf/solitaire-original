# 經典接龍｜Klondike Solitaire

現代化、無框架的經典接龍網頁遊戲。支援桌機、iPad 與手機，提供點選移動、拖曳、無限復原、提示、翻一張／翻三張、遊戲編號、統計與計時挑戰。

▶️ **正式遊玩：<https://zerokemf.github.io/solitaire-original/>**

## 主要特色

### 完整 Klondike 規則

- 7 列牌桌，紅黑交替遞減排列。
- 4 個固定花色基礎牌堆，依 A 到 K 遞增。
- 空列只能放 K 或以 K 開頭的合法牌組。
- 支援翻一張與翻三張，牌庫可循環使用。
- 基礎牌堆頂牌可退回牌桌，不會被死局偵測誤判。

### 操作體驗

- **點選移動：** 點一下選牌，再點目的地。
- **拖曳移動：** 可直接拖曳單張或合法牌組。
- **雙擊自動上牌：** 只有來源牌堆頂牌能自動移到基礎牌堆。
- **經典破關動畫：** 四個基礎牌堆輪流逐張發射，紙牌受重力落下並在地板與左右邊界反彈；動畫只操作畫面副本，不會破壞已完成牌局。
- **鍵盤操作：** `Space` 翻牌、`H` 提示、`N` 新遊戲、`T` 切換主題、`Ctrl/Cmd + Z` 復原。
- **無限流程復原：** 記錄最近 30 個狀態；勝利後也能正確復原並恢復計時。

### 響應式介面

- 桌機牌桌在 1280–3440px 維持適中寬度；牌距固定約為牌寬 30%，並限制在 28–52px。
- 放大／縮小會同步調整牌寬、牌距與牌區寬度，不會忽然貼太近或拉太遠。
- 桌機與 iPad 保留完整工具列與適合各自尺寸的牌面。
- 手機固定顯示完整 7 列，不會裁掉第 7 列或產生橫向捲動。
- 手機使用固定底部主要操作列；其他功能收進「更多」工具抽屜。
- 觸控目標至少 44×44 px，支援安全區與 `prefers-reduced-motion`。
- 對話框、狀態按鈕與可操作紙牌具備基本 ARIA 語意與鍵盤焦點。

### 牌局與資料

- 遊戲編號範圍為 1–32000；輸入的編號不會被可解性搜尋偷偷改號。
- 每個編號使用獨立的候選 seed 序列，經解牌器檢查後建立可解牌局。
- 自動存檔包含目前牌局、時間、步數、復原紀錄及翻一張／翻三張模式。
- 恢復前會驗證 52 張標準牌是否完整且不重複；損壞存檔會安全清除。
- 統計包含遊戲數、勝場、勝率、最快時間、最少移動與連勝。

## 本機執行

本專案不需要建置即可遊玩：

```bash
python3 -m http.server 8000
```

開啟 <http://localhost:8000>。

## 測試

需要 Node.js 20 以上版本與本機 Chrome：

```bash
NODE_ENV=development npm install
npm run verify
```

測試分為：

- **邏輯測試：** Node `test` + VM DOM stub，驗證規則、存檔、死局、遊戲編號與勝利狀態。
- **瀏覽器 E2E：** Playwright + Chrome，驗證點選移動、復原、主題、翻三張存續、遊戲編號、對話框、手機七列與底部操作列。

個別執行：

```bash
npm run test:logic
npm run test:e2e
```

## 專案結構

```text
solitaire-original/
├── index.html                 # 遊戲介面與對話框
├── style.css                  # 響應式設計系統與牌面樣式
├── game.js                    # Klondike 規則、狀態與互動
├── favicon.svg                # 網站圖示
├── package.json               # 測試腳本
├── playwright.config.js       # 瀏覽器測試設定
└── tests/
    ├── solitaire.test.js      # 遊戲邏輯回歸測試
    ├── helpers/               # VM 測試環境
    └── e2e/                   # 真實瀏覽器驗收
```
